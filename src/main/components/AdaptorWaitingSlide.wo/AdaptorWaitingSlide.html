Requests that wait

  • Every request on a virtual thread: 2,000 requests waiting 200 ms are served at about 10,000 a second, p99 within 25 ms of the wait
  • The classic adaptor serves 256 at a time, tops out near 1,280 a second, and resets the connections it has no room for
  • JettyMaxConcurrentRequests=50 queues the rest exactly as configured, none failed
  • WO's request lock still applies: concurrent request handling off, a waiting direct action drops from 487 req/s to 2

From github.com/undur/wo-adaptor-jetty-bench: wo-adaptor-jetty 0.12.3 against WO's classic adaptor, client and server on one 14-core Mac
