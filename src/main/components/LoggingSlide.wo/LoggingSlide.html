Logging

No log4j needed, and pluggable backends such as logback

Properties

er.logging.level.root=INFO
er.logging.level.com.example.billing=DEBUG
er.logging.pattern=%d{MMM dd HH:mm:ss} %-5p %c - %m%n
  • Based on slf4j
  • A console logger built in: no logging framework needed
  • WebObjects' own NSLog ends up in the same log
  • Levels change on the running instance

Files, rotation, appenders? Add one

<dependency>
	<groupId>is.rebbi.slim</groupId>
	<artifactId>ERLoggingLogback</artifactId>
</dependency>
  • Or ERLoggingReload4j, for existing log4j configuration
  • The same keys work with either, or neither
