Supports both WOOgnl-style inline bindings and .wod templates

.wod: two files

<webobject name="Name" />
Name : WOString {
	value = person.name;
}

Inline: one

<wo:str value="$person.name" />
<wo:str value="Hello" />
<wo:if condition="$true">…</wo:if>
  • $ is a keypath, anything else a constant
  • The WOOgnl syntax, without needing OGNL
