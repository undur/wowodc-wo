Namespaces you register

Application.java

Parsley.configure()
	.elementFactory( "html",
		new ParsleyHTMLElementFactory() )
	.register();

Then, any HTML tag is dynamic

<html:a href="$url" class="$linkClass">
	Read more
</html:a>
<html:input type="checkbox" checked="$isChecked" />

Instead of

<wo:container elementName="a"
	href="$url" class="$linkClass">
	Read more
</wo:container>
  • A namespace is a name and a factory that makes its elements
  • wo: is always there; unregistered ones (svg:, xsl:) are plain HTML
  • This deck's progress bar is an <html:div>
