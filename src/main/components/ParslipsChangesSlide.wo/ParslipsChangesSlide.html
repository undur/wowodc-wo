Parslips, from its changelog

Editing templates

  • Tag and attribute completion; self-closing tags arrive with their required bindings
  • Close-tag completion that knows void elements, scripts, p:raw and p:comment
  • A formatter that keeps your lines, blank lines and &nbsp;
  • Standalone .html templates, not just .wo bundles
  • Maven and Fluffy Bunny layouts
  • Inline ↔ WOD, one tag or a whole template; bundle ↔ standalone
  • F3 on a tag; Cmd+Alt+1 to the Java, Cmd+Alt+5 to the API
  • Highlighting that follows Eclipse's theme

Validation

  • Bindings checked as you type, and again when the Java is saved or the classpath changes
  • Revalidate every template in a project, with honest problem counts
  • Missing > and =, duplicate attributes, stray close tags
  • Bindings that can't be pushed back to a synchronizing parent
  • KVC operators on Java collections
  • Route links checked, their parameters completed

Quick fixes and refactoring

  • "Did you mean?" for keypaths and element names
  • Create the missing key or action from Cmd+1
  • Rename a component, key or element across Java, HTML and WOD
  • Extract Component, Extract Wrapper
  • Find References and a Usages tab that include the templates

Element APIs

  • .apiext for every standard WebObjects element
  • Hovers with types, direction, docs and the alias chain
  • An Element Reference view
  • The API tab edits .apiext and writes the .api
  • Each project's own tag aliases, for WO and for ng

WebObjects and ng-objects

  • Both in one plugin, decided per template, so hybrid projects work
  • A Parsley perspective and Explorer
  • Installs next to WOLips: shared content types, its keybindings respected

The dev server

  • On by default, no password, and back after an Eclipse restart
  • Launch, stop, restart, status, console: every answer says what happened
  • Refresh, validate and problems as JSON
  • Create or import a project and run it, in one call
  • Why an app hangs: threads, dialogs, breakpoints
  • Ask the editor: context, keypaths, usages, callers, renames, quick fixes
  • Click a stack trace in the browser, land in Eclipse
  • An activity feed, and a live page to watch an agent work

Removed

  • EOF and EOModeler: about 130 files
  • Plist, JSP, XML/DTD, display group, JavaScript and CSS editors
  • Velocity, Rhino, JTidy, Xerces, Ant and the old builders
  • PB.project and patternsets
