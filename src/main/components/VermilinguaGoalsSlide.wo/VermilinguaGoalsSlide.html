Deploying, from Maven

Two goals, both still experimental

vermilingua:deploy, through JavaMonitor

mvn package vermilingua:deploy \
	-Ddeploy.monitorHost=https://monitor.example.com \
	-Ddeploy.password=…
  • Uploads the built .woa to JavaMonitor's deploy endpoint
  • wotaskd puts it on every host the application runs on
  • Settings in build.properties or as -D, like everything else

vermilingua:ssh-deploy, straight to a server

mvn vermilingua:ssh-deploy -Ddeploy.host=me@myserver
  • rsync into a new release folder: a redeploy sends only what changed
  • Installs Java on the server, and keeps it updated with every deploy
  • Keeps the five newest releases
  • Or name an exe.dev VM: -Ddeploy.exe.vm=myvm, created if it doesn't exist
