Overriding build.properties

build.properties

launch.jvm=/opt/jdk-25/bin/java
launch.jvmOptions=-Xmx2g

When building

mvn package -Dlaunch.jvm=/opt/jdk-26/bin/java

When launching

./MyApp.woa/MyApp "-launch.jvmOptions=-Xmx4g"

Per environment: build.properties.prod

mvn package -Dbuild.env=prod

First match wins

  1. -launch.* arguments to the launch script
  2. -D properties when building
  3. build.properties.<env>, with -Dbuild.env
  4. build.properties
  5. Built-in defaults
  • A different JVM or more memory on one server, without changing a committed file
  • The launch script uses -launch.* arguments itself; the application never sees them
