A huge amount of cleanup

Modernization

  • Maven instead of ant, one reactor build, released to Maven
  • Java 11 → 17 → 21 → 25
  • Java's List and Map, records, java.time and lambdas, wherever the API is ours
  • Generics and current syntax throughout what was kept
  • Typed notifications with lambda observers, instead of strings and selectors
  • Small value types as records: the user agent, route handlers, notification observers
  • Configuration composed once in main(); frameworks as ServiceLoader plugins

Deleting utility code

  • Most of the ERX*Utilities: arrays, strings, files, dictionaries. The JDK does it now
  • ERXMoney, Joda support, BCrypt and crypto, dozens of formatters
  • ERXExpiringCache, ERXMutableURL, ERXSimpleTemplateParser, ERXActionLogging
  • About 100 ERX components: tab panels, batch navigation, matrices, RSS, ERXClippy…
  • About 35 Prototype widgets from Ajax
  • Dependencies: commons-lang, commons-codec, httpclient, icu4j, joda-time, log4j

Cleaning up code and design

  • About 690 commits that delete or remove something, and about 190 called "cleanup"
  • EOF support out: ERExtensions went from 525 classes to 223
  • ERXPatcher's runtime class swaps → substitutions declared in a file
  • ERXLoader's 845 lines of classpath munging → a check that fails loudly
  • ERXLocalizer → ERXLocale; the browser pool → ERXUserAgent
  • ERXP: every property ERExtensions reads, in one place; 309 obsolete ones named at startup, each with why
  • Every element documented in .api and .apiext
  • Javadoc and comments rewritten in the code that stayed
